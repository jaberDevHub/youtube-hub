# YouTubeHub: Single-Page Creator Profile Platform

Build YouTubeHub, a GitHub-inspired platform for YouTube creators. The entire product revolves around one beautiful, shareable public profile homepage per creator.

## Core concept

The creator pastes their YouTube channel URL, clicks "Generate Profile", and YouTubeHub automatically creates their profile using available YouTube data.

No complicated dashboard. No separate tabs. No multi-page profile navigation. No unnecessary interfaces hidden behind buttons.

**One URL in. One complete creator homepage out.**

## 1. Profile generation

The landing page should have a simple input:

"Paste your YouTube channel URL..."

Button: "Generate My Profile"

Resolve the URL, retrieve available channel data from the official YouTube Data API, and generate a permanent public profile URL such as:

`youtubehub.com/@jaberdevhub`

The creator should not need to manually enter their channel name, avatar, subscriber count, description, or video list.

## 2. The complete profile homepage

Everything below belongs on a single, vertically scrollable page.

### A. Profile header

At the top, display:
- YouTube channel avatar and banner
- Channel name and handle
- Channel description
- Link to the original YouTube channel
- Follow button, if the viewer is logged in
- Share profile button
- Copy profile link button
- Creator level badge
- Optional creator-written bio and social links

### B. Creator statistics

Display a compact row of statistic cards:
- Subscribers
- Total channel views
- Total published videos
- Creator level
- YouTubeHub ranking

Use genuine available data and clearly distinguish unavailable statistics.

### C. Contribution graph

Make this the signature feature, inspired by GitHub's contribution calendar.

Display a 12-month heatmap directly on the homepage, with months across the top and weekly columns of colored daily cells.

Track creator activity such as:
- Video uploads
- YouTube Shorts
- Livestreams
- Community posts, where available
- Subscriber milestones
- View milestones

Hovering over a cell should reveal a tooltip with the date and available activity details.

Below the graph, show:
- Total activities this year
- Current publishing streak
- Longest streak
- Active weeks
- Videos published this year

Use YouTube red for the activity intensity scale, with subtle dark cells for inactive days.

Important: only show historical activity supported by real records. Start collecting snapshots and activity events once a channel is added. Do not invent a historical contribution history.

### D. Creator level progression

Display a visual level badge and progress bar.

- Newcomer: 0–999 subscribers
- Rising Star: 1K–9.9K
- Creator: 10K–99.9K
- Pro Creator: 100K–999.9K
- Icon: 1M–9.9M
- Legend: 10M+

Show the current level, subscriber milestone, and progress toward the next level.

### E. Achievements

Display collectible achievement badges directly on the page.

Examples:
- First Upload
- 100 Videos
- 1K Subscribers
- 10K Club
- 100K Club
- Million Club
- Consistency Streak
- 1 Million Views

Each badge should show its name and unlock condition. Only award achievements when their conditions are supported by available data.

### F. Featured videos

Show a responsive grid of real videos from the channel.

Each video card should include:
- Thumbnail
- Video title
- Publication date
- View count, when available
- Duration
- Link to watch on YouTube

Show a sensible number of recent videos and allow a "Load more" interaction that expands the grid inline. Do not navigate to a separate Videos page.

### G. Creator statistics and growth

Show a compact chart section directly below the contribution graph or featured videos.

Include subscriber history, view growth, upload frequency, and publishing activity only when historical data exists.

Keep the charts compact, attractive, and integrated into the page rather than creating a separate analytics dashboard.

### H. Rankings

Include a compact leaderboard or ranking summary showing:
- Global ranking
- Regional ranking, when the creator has voluntarily selected a region
- Category ranking, when supported
- Ranking methodology

Place a few relevant leaderboard entries directly on the homepage. Any additional entries can expand inline rather than opening a separate page.

### I. About and links

At the bottom, display the creator's optional bio, social links, categories, joined date, and profile metadata.

## 3. Visual direction

Make it look like a polished GitHub creator profile with YouTubeHub's own identity.

Use:
- Dark graphite background
- White and gray typography
- YouTube-red contribution heatmap
- Thin borders and restrained shadows
- Compact statistic cards
- Clear visual hierarchy
- Clean, consistent spacing
- Responsive desktop and mobile layouts
- Optional light theme

Avoid excessive gradients, purple neon effects, giant cards, unnecessary animations, and generic AI-generated SaaS styling.

The profile should look information-rich and professional, not cluttered.

## 4. Interactions

Keep all interaction within the same homepage.

Allowed interactions:
- Generate profile from URL
- Copy profile link
- Share profile
- Hover over contribution cells
- Expand recent videos
- Switch contribution graph filters inline
- Expand achievement details inline
- Follow creator
- Edit profile if the authenticated owner is viewing it

Do not build separate profile tabs, separate statistics pages, or a multi-screen dashboard.

The only separate route required is the initial profile-generation page and each creator's permanent public profile URL. After generation, the creator's profile is one complete homepage.

## 5. Data and technical requirements

Use React and Vite for the frontend, a persistent database such as Supabase or PostgreSQL, and the official YouTube Data API for supported public channel data.

Use real channel IDs, real thumbnails, and real video metadata. Keep API keys on the server. Add caching, rate limiting, loading states, error handling, and duplicate-channel detection.

For public profiles, use stable URLs that work on any device. Do not rely on browser localStorage or encoded profile data as the permanent sharing mechanism.

Record available metric snapshots and activity events over time so the contribution graph and historical charts become increasingly useful.

Never fabricate subscriber history, daily views, contributions, rankings, or verified achievements.

## Final objective

The result should feel like opening someone's GitHub profile, except it tells the story of their YouTube channel.

A visitor opens one URL and immediately sees who the creator is, how large their audience is, how consistently they publish, what achievements they have earned, their best videos, their growth, and their position in the creator community.

Everything important is visible on one polished, scrollable homepage.
