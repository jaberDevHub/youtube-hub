## ✨ Signature Highlights

### 🔴 Ambient Light Blur Theme
* Atmospheric crimson glowing ambient light mesh (`rgba(255, 0, 51, 0.4)`) with animated floating orbs.
* Deep graphite canvas with glassmorphism (`backdrop-filter: blur(28px)`) and a subtle red laser accent edge.
* Designed specifically for viral social screenshots on Twitter/X, Discord, and LinkedIn.

### 📅 12-Month GitHub Contribution Heatmap
* GitHub-inspired calendar tracking 365 days of upload activity.
* YouTube Red intensity scaling for video uploads, Shorts, and milestones.
* Real-time metrics: Publishing streak, longest streak, active weeks, and yearly upload count.

### 🏆 Circular Play Button Achievements
* Visual collectible medallion awards modeled directly after GitHub's icon system:
  * 🥈 **Silver Play Button** (100K Subscribers)
  * 🥇 **Gold Play Button** (1M Subscribers)
  * 💎 **Diamond Play Button** (10M Subscribers)
  * 🔴 **Custom Ruby Play Button** (50M Subscribers)
  * 💎 **Red Diamond Play Button** (100M Subscribers)
  * 🌌 **Cosmic Play Button** (200M Subscribers)
  * 👑 **Mythic Apex Play Button** (300M Subscribers)

### 📸 Instant High-Resolution Image Export
* **Share Image** button generates a clean, crystal-clear 2x PNG screenshot with zero button clutter, ready for social sharing.
* Fits 100% within a single viewport with zero vertical scrolling needed.

## 🔐 Environment Variables for Vercel

When deploying to Vercel, configure this environment variable in your Vercel Dashboard under **Settings > Environment Variables**:

| Variable Name | Description | Example |
|---|---|---|
| `VITE_YOUTUBE_API_KEY` | Official Google YouTube Data API v3 Key | `AIzaSy...` |

*(This keeps your API key secure on the server side and out of public Git commits)*
